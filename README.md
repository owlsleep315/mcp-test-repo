# MCP Test Repository

이 레포지토리는 GitHub MCP (Model Context Protocol) 기능을 테스트하기 위해 생성되었습니다.

## 테스트된 기능들

- ✅ 레포지토리 생성
- ✅ 브랜치 생성 (`feature/test-mcp`)
- ✅ 파일 추가 및 커밋
- ✅ Pull Request 생성 예정

## 파일 구조

- `test-file.txt` - MCP 테스트용 파일
- `README.md` - 이 파일

## 사용된 MCP 도구

- GitHub MCP 서버
- Smithery AI 통합
